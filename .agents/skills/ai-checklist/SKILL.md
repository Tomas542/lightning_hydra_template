# AI checklist for ML Research

## Overview

Comprehensive AI & Research Compliance Checklist, that saves results to `docs/ai-checklist.md`. This compliance checklist integrates **FAIR** data stewardship, the **REFORMS** framework for robust machine learning, and the complete **Open Ethics Canvas** framework into a single executable workflow for machine learning research repositories.

## When to Use

Use this skill when

- Drafting research papers.
- Reviewing model cards.
- Preparing submissions.
- Need for code verification according to community standards.

## AI Ethics and Checks

Ensure adherence to our governance frameworks stored in `docs/ethics/`:

- **Data Stewardship:** Verify compliance against `docs/ethics/fair-principles.md`.
- **Methodological Rigor:** Check evaluation and leakage controls using `docs/ethics/reforms-framework.md`.
- **Responsible AI & Impact:** Complete the relevant sections of `docs/ethics/open-ethics-canvas.md`.
